# BATAPRO — 100% Free Forever ATS Resume & CV Builder

An ultra-fast, lightweight, SEO-first Next.js (App Router) + TypeScript web application for building ATS-compatible Resumes & CVs in **Arabic (RTL), French, English, Spanish, and German**.

## Highlights
- **100% Free Forever:** Zero paywalls, zero trials, zero watermarks. Instant guest usage with automatic LocalStorage persistence + optional free cross-device Cloud Sync.
- **Technical SEO:** Localized routes (`/en`, `/fr`, `/ar`, `/es`, `/de`), dynamic `generateMetadata` + `hreflang` canonicals, Schema.org JSON-LD (`WebApplication`, `SoftwareApplication`, `HowTo`, `FAQPage`, `Article`, `CollectionPage`), `/sitemap.xml`, `/robots.txt`, `/opengraph-image`, and `/[lang]/guides`.
- **ATS Vector PDF Export:** Crisp selectable-text A4 PDFs via `@react-pdf/renderer` and clean `@media print` A4 rules.
